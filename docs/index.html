CHASM

Copy-number analysis tools for scATAC-seq

CHASM packages the wavelet-transform, segmentation, and copy-number inference code from the scATACcnv project into reusable R functions.

Open Tutorial Vignette Read README

What This Package Covers

Wavelet Workflow

Normalize binned read depth, apply chromosome-aware wavelet transforms, denoise with robust PCA, and assign segment-level copy-number states.

Chromosome Workflow

Run chromosome-level negative-binomial calling and combine it with segment-level evidence into final copy-number state calls.

Bundled Examples

The package ships with example read-depth matrices and a rendered tutorial vignette so the workflow can be explored without external setup.

Start Here

  1. Install the package dependencies listed in the README.
  2. Load the package with pkgload::load_all() for development or install it as a source package.
  3. Open the tutorial vignette to see the bundled workflow and heatmap output.
